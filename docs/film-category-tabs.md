# Film Shelf native category tabs

November 26, 2026 Beijing. Base ddc8d51, no pre-existing dirty paths. Bounded lane: make the native category tabs match Film Shelf Home, switch on touch without opening a filter for the wrong tab, and scroll without snapping or refreshing mid-list. Scope: leanback VodActivity native header/tab styling, type adapter, category grid input/refresh; reuse existing result, category, playback, filter and paging ownership. No player, private source, web Home, mobile flavor, or public branch changes. Target end ~15:47 Beijing (implementation 4 min, warm ARM64 build 3 min, targeted QA 5 min). Reversible with this patch.

Evidence: on Y700 (base ddc8d51), first category swipe stayed at the same anchor; the second moved, so the category symptom is intermittent. Home opens VodActivity, which uses a separate tab adapter and TypeFragment inside a pager. The exact Leanback 1.0.0 Category grid retained default aligned scroll and only the recommendation Home had the touch exception. The SwipeRefreshLayout direct child is ProgressLayout rather than the actual scrollable grid; the [official callback API](https://developer.android.com/reference/androidx/swiperefreshlayout/widget/SwipeRefreshLayout#setOnChildScrollUpCallback(androidx.swiperefreshlayout.widget.SwipeRefreshLayout.OnChildScrollUpCallback)) lets the app supply the real top boundary. Exact shipped Leanback grid has no implementation of computeVerticalScrollOffset, so measure attached adapter row zero instead of depending on RecyclerView scrollbar metrics. VodActivity also requested tab focus after every page selection (including touch), and every tab click toggled a filter rather than first checking that it is the current tab. [Android TV D-pad guidance](https://developer.android.com/training/tv/get-started/navigation) supports retaining focus-first remote navigation and explicit selection.

Keep the existing data model and pager rather than rewrite provider/filters in Compose; baseline no-op leaves an inconsistent second screen, global theme/grid changes risk changing unrelated players/settings. Adapt the proven Home touch alignment exception to the category grid only, keep D-pad auto-focus/tab behavior, and use the shared Film Flow color/actions. Test physical recommendation → one tap on category → two swipes forward and reverse → second tab in one tap → toggle its filter and return. This is native browse, not a rewrite of provider-supplied web pages. No dependency or upstream integration, paper, or benchmark is relevant.

Recovery anchor: implement exact scoped paths, build and install on idle authorized Y700, check physical swipes and cancellation of stale pager focus updates; emulator fallback only if needed.
