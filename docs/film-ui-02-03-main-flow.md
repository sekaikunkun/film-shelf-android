# Film Shelf main flow: FS-UI-02 / FS-UI-03

Approved November 26, 2026. Develop on the existing leanback ARM64 build, with no dependency, player, persistence, private source or repository publication changes.

## Decision

- [Android IME visibility](https://developer.android.com/develop/ui/views/touch-and-input/keyboard-input/visibility), Android official, accessed 2026-11-26: show the system IME for an explicitly focused editor through the window insets controller. The app does not choose or install the keyboard language. Read the actual platform guidance rather than assuming an in-app Latin/Zhuyin grid does Chinese composition.
- [TV navigation](https://developer.android.com/training/tv/get-started/navigation) and [Compose interoperability](https://developer.android.com/develop/ui/compose/migrate/interoperability-apis/compose-in-views), official references originally reviewed in the architecture index: separate focus from activation; reuse an existing application boundary. Google JetStream is a visual/navigation reference, not a replacement player or search stack.
- Local source: CustomSearchView always reported focus, SearchActivity routes one committed editor value to CollectActivity, and existing TV keys/phone push remain necessary. CollectActivity owns asynchronous provider fetch/filtering, SearchAdapter owns loaded rows, and VideoActivity owns detail/history/player callbacks. FamilyScanProgress already consumes actual scanner counters; replacing it with animation-timed progress would regress honesty.
- No change leaves the platform keyboard hidden behind an unlabeled field and handoffs inconsistent. A full Compose rewrite would put current grid pagination, provider routes and player lifecycle at risk. Use existing native surfaces with shared design resources, explicit input/action affordances, conservative display grouping (not a playback identity merge), and state/focus handoffs. Existing design index covers primary sample/source/releases; no upstream PR/native component, public data contract, or benchmark claim applies. Dependency and ABI unchanged. Roll back this single scoped patch; no database migration.
